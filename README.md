# EA FC Tournament – Companion App

Proyecto académico individual (Desarrollo Móvil). App móvil (Expo) + backend propio (FastAPI) + Supabase. Ver `CLAUDE.md` y `docs/PROGRESS.md`.

## Aviso sobre datos e imágenes
Uso académico, no comercial. Los escudos, nombres y fotos de clubes y jugadores, y las valoraciones de EA SPORTS FC, son propiedad de sus respectivos dueños (clubes, ligas, Electronic Arts). Los datos de plantillas proceden de SoFIFA y las clasificaciones de Wikipedia. Detalles en `docs/scraping/scraping.md`.
